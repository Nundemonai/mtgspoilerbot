I just merely created it for a little fun proj at home.

What it is?
It's a discord bot that sends MTG spoilers to a specific channel that you create manually.

How to install?
press on <> CODE
Press download as ZIP
Put the contents somewhere you remember
Open a CMD prompt
CD into the directory E.G full command cd /home/*yourUserName*/mtgspoilerbot (If you are Linux/RPI user. if you want to put it there, that is.)
run the command source /mtg_spoiler/bin/activate
run the command pip install -r requirements.txt
run the command sudo nano config.py and change settings for the bot and follow the instructions.
run the command python main.py to run it.
